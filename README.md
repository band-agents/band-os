# band. OS

The work of band., a studio in Cairo, shown on the studio's own desktop.

**Live:** https://band-agents.github.io/band-os/

- It boots with the barcode logo. The bars rise one by one and the wordmark writes itself.
- Stores, Apps, Brands, Software, Results, Services and Start a build are folders and windows you can drag around.
- **bqnd**, the assistant, lives in the command bar. Press `⌘K` / `Ctrl+K` (or `/`), then type a question or the name of a window. It answers from band.'s real work and numbers, and opens the right windows for you.

It is one static page with no build step and no dependencies. Fonts come from Google Fonts, and the project images are in `img/`.
